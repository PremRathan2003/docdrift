# Task API

A small JSON API for managing a to-do list. It keeps tasks in memory, so it is
meant for demos and tests, not production.

## Quick start

```bash
npm install
npm start
```

## Tasks

Each task looks like this:

```json
{ "id": 1, "title": "Buy milk", "done": false }
```
